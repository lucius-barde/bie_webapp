🚀 DÉMARRAGE RAPIDE

1. Installation (2 min)
   $ npm install

2. Configuration (1 min)
   - Copier .env.example → .env.local
   - Ajouter clés Supabase

3. Démarrage dev (immédiat)
   $ npm run dev
   → http://localhost:5173

4. Build (production)
   $ npm run build
   → dist/

📋 ROUTES DISPONIBLES

/                               Page d'accueil
/musique                        Liste des chants (page 1)
/musique/page/:page             Pagination
/musique/:songId-:slug          Détail d'un chant

Exemple URL: /musique/12-ce-que-laino
- 12 = song_catalog_id
- ce-que-laino = slug généré automatiquement
